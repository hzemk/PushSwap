<h2>                Descriptions                <h2/>

<p> this project for sorting a stack of integers using a limited set of stack operations..
The goal of the project is to sort the numbers with the minimum possible number of operations,the program receives integers as command-line arguments and prints the sequence of operations required to sort them in ascending order. <p/>

<h2>                Instructions                <h2/>

<h3>                Compilation                 <h3/>
   1. clone this to your repository:
    ```bash
    git clone git@github.com:42learners/Common-Core---Push_Swap-9233bf73-6072-4e07-812d-dfece7920e37.git
    cd pushswap
    ```
    2.Compile the library by running the following command:
    ```bash
    make
    ```
    This will compile the library and generate the `pushswap` static library file.

<h3>                  Installation               <h3/>

    - To use the library in your project, simply copy or link the `libftprintf.a` file into your project directory.
    - Add the path to `pushswap` in your compilation commands. For example:
    ```bash
    gcc -o your_program your_program.c -L/path/to/pushswap -lft
    ```
